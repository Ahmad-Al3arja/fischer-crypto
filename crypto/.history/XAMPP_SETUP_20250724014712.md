# XAMPP Setup Guide for Investment Platform

## Prerequisites
- XAMPP installed and running
- Java 17 or higher
- Maven

## Database Setup

### 1. Start XAMPP Services
1. Open XAMPP Control Panel
2. Start Apache and MySQL services
3. Ensure MySQL is running on port 3306

### 2. Create Database
You have two options:

#### Option A: Using phpMyAdmin (Recommended)
1. Open your browser and go to `http://localhost/phpmyadmin`
2. Click on "New" to create a new database
3. Enter database name: `investment_platform`
4. Select collation: `utf8mb4_unicode_ci`
5. Click "Create"

#### Option B: Using the provided SQL script
1. Open phpMyAdmin
2. Click on "SQL" tab
3. Copy and paste the contents of `database-setup.sql`
4. Click "Go" to execute the script

**Note**: With Flyway migrations, you can also just create an empty database and let the application handle the schema creation automatically.

### 3. Database Configuration
The application is already configured to use XAMPP MySQL with these settings:
- **Host**: localhost
- **Port**: 3306
- **Database**: investment_platform
- **Username**: root
- **Password**: (empty - default XAMPP setting)

## Application Setup

### 1. Environment Variables (Optional)
You can set these environment variables if you want to customize the database connection:

```bash
# Windows (Command Prompt)
set DB_USERNAME=root
set DB_PASSWORD=
set JWT_SECRET=your-secret-key-here

# Windows (PowerShell)
$env:DB_USERNAME="root"
$env:DB_PASSWORD=""
$env:JWT_SECRET="your-secret-key-here"

# Linux/Mac
export DB_USERNAME=root
export DB_PASSWORD=
export JWT_SECRET=your-secret-key-here
```

### 2. Run the Application
```bash
# Navigate to project directory
cd crypto

# Clean and compile
mvn clean compile

# Run the application
mvn spring-boot:run
```

### 3. Verify Setup
1. Application will start on `http://localhost:8080`
2. Swagger documentation: `http://localhost:8080/swagger-ui.html`
3. Health check: `http://localhost:8080/actuator/health`

## Troubleshooting

### Common Issues

#### 1. Connection Refused
- Ensure XAMPP MySQL service is running
- Check if port 3306 is not blocked by firewall
- Verify MySQL is listening on localhost

#### 2. Access Denied
- Default XAMPP MySQL root password is empty
- If you set a password, update the `application.yml` file

#### 3. Database Not Found
- Ensure the database `investment_platform` exists
- Run the database setup script if tables are missing

#### 4. Character Encoding Issues
- Database is configured with `utf8mb4_unicode_ci` collation
- Application uses UTF-8 encoding

### Reset Database
To completely reset the database:
1. Drop the `investment_platform` database in phpMyAdmin
2. Recreate it using the setup script
3. Restart the application

## API Endpoints

### Authentication
- `POST /api/auth/register` - User registration
- `POST /api/auth/login` - User login
- `POST /api/auth/logout` - User logout

### User Management
- `GET /api/user/profile` - Get user profile
- `PUT /api/user/profile` - Update user profile
- `GET /api/user/dashboard` - Get user dashboard

### Plans
- `GET /api/plans` - Get all plans
- `POST /api/plans/{planId}/subscribe` - Subscribe to plan

### Transactions
- `POST /api/transactions/deposit` - Create deposit
- `POST /api/transactions/withdraw` - Create withdrawal
- `GET /api/transactions/history` - Get transaction history

### Admin (Admin role required)
- `GET /api/admin/users` - Get all users
- `PUT /api/admin/users/{userId}/status` - Update user status
- `GET /api/admin/statistics` - Get platform statistics
